# 💳 PORTEFEUILLE ÉLECTRONIQUE — GROUPE 13

Présentation du projet

Bienvenue sur le dépôt officiel du projet de portefeuille électronique du Groupe 13.

Ce projet consiste à concevoir et développer une application permettant aux utilisateurs de gérer leur argent de manière numérique, simple et sécurisée.

🎯 Objectifs

- Créer un système de gestion de portefeuille électronique.
- Permettre l'inscription et l'authentification des utilisateurs.
- Consulter le solde du portefeuille.
- Effectuer des dépôts et des retraits.
- Réaliser des transferts entre utilisateurs.
- Consulter l'historique des transactions.

🛠️ Technologies utilisées

- Java : logique et développement de l'application.
- Base de données : stockage des informations.
- Git et GitHub : gestion du code source et collaboration.

📁 Organisation du projet

- "src/" : code source.
- "database/" : scripts et données de la base de données.
- "docs/" : documentation du projet.
- "README.md" : présentation du projet.

👥 Équipe de développement

Groupe 13

Les membres de l'équipe sont responsables de la conception, du développement, des tests et de la documentation.

🔄 Méthode de collaboration

- "main" : version stable.
- "develop" : intégration des fonctionnalités.
- "feature/*" : développement des fonctionnalités.

Les modifications sont proposées à travers des Pull Requests avant leur intégration.

📌 État du projet

Projet en cours de développement.
